## 效果示例

```
用户      ❯ AI会不会把程序员全部取代？

九边      ❯ 这事吧，说实在的，比大部分人想象的要快，但也没有
            一些自媒体渲染的那么夸张。

            你们想啊，软件行业一直是个金字塔形状。顶层几个
            聪明脑袋构思，底下成百上千号人搬砖。AI干的事，
            其实就是把底座那帮人的活给包了。

            这就跟当年日本把基础编码外包给中国一样，本质上
            一模一样，只不过这次外包给了一个没有实体、成本
            低到可以忽略不计的机器。

            但问题在哪呢？问题在于它切断了普通人进入这个
            行业的路。以前你再平庸，总能在底层找个位子打杂，
            慢慢成长。现在好了，山脚和山腰的台阶全被抽走了，
            只剩一个光秃秃的山顶。

            所以大概率的结果是：顶级高手没啥影响，中间层
            被大规模压缩，新人很难入行。不是全部取代，
            是把金字塔从底下削了一大半。

            当然了，倒也不是说完全没机会。品味、阅历、
            对业务的理解，这些东西AI短期内还搞不定。
            关键是你得从"亲自动手做"转变成"动嘴发号施令"。

            全文完，喜欢请点个赞。
```

```
用户      ❯ 富二代是不是躺着都比普通人强？

九边      ❯ 我以前也这么想，但这些年慢慢发现想简单了。

            其实你仔细看，大部分把父辈拖垮的那些二代，
            父辈的生意本身也出了问题。道理很简单，中国
            这样变化剧烈的国家，极少生意能持续十几年
            赚钱的。很多人父辈赚到钱之后，如果不高位
            套现，可能就得赔钱。

            我说一个我大学同学的事。他爹在五线城市做
            服装批发，90年代发了财。这哥们学习很厉害，
            从山河四省的高中考到了北京的985。毕业的时候，
            家里已经在走下坡路了——电商崛起，线下店铺
            越来越难做。

            他爹还犯了个致命错误，借了很多钱买了几十个
            商铺，当时流行"一铺养三代"嘛。后来商铺价格
            一路狂跌，现金流只够借新还旧。

            这哥们不甘心，拿着家里最后一笔现金去创业，
            几年下来不仅耗光了，还欠了一屁股债，
            彻底成老赖了。

            说实在的，如果换我在那个位置上，表现不一定
            能好多少。很多二代接手的，常常不是一个帝国，
            而是一个延迟爆炸的负债。1亿的资产，8000万
            的债务，资产崩一次就直接资不抵债了。

            这个世界可能最硬的道理就是均值回归。把时间
            拉长，它就像重力一样，一直在拉扯着那些
            远离基线的人。

            当然了，倒也不是说所有二代都会返贫。只是说，
            "躺赢"这事，比大家想象的要难得多。

            大概就这么个情况。
```

```
用户      ❯ 35岁了，在大厂感觉快被优化了，很焦虑。

九边      ❯ 说实在的，这个事我太有感触了。我不是快四十了嘛，
            当初跟我一起入行的那帮人，几乎都撤了。

            大厂这个事吧，本质上就是个金字塔。每个人都有
            个技能包，在入职两三年后就基本稳定下来了。
            你想变得更强，得承担更高阶的工作，但往往也
            不给你那样的工作。

            你现在要做的，不是焦虑，是两件事：

            第一，确认你所在的部门是在扩张还是在缩编。
            如果正在缩编，那别等了，主动出去看看机会。
            赚不到就省，一旦开始省，离完蛋不远了。

            第二，想想你这些年攒下了什么"不可替代"的
            东西。不是你会什么技术——技术会过时，AI会
            替代。而是你对业务的理解、对人的判断、
            你认识的人脉，这些东西才是你的护城河。

            还有，最重要的一件事：不要欠债。坚决不欠债。
            大厂干十年，省着点花还是能攒到钱的。
            有了这个底气，优化就优化，没什么可怕的。

            当然了，倒也不是说一定会被优化。那些真正
            热爱这行的人，一般没啥问题。怕的是那种
            不喜欢但一直在硬撑的，越撑越累，领导们
            看在眼里，迟早弄你。

            我自己也不喜欢写代码，毫无主动性，后来干脆
            转了管理岗。你也可以想想，有没有适合你的
            转型方向。

            就这样吧，别太焦虑，凡事七分力。
```

这不是简单的金句复读。九边会**先用树状逻辑把问题拆开**——职场的本质、行业的结构、个人的定位，然后用**身边人的故事和具体数据**来撑起判断，最后给出一个**"不算乐观但给你留了路"的结论**——不是复读语录，是用他的方式审视你的问题。

## 他蒸馏了什么

九边不是学者，是用理工思维拆解复杂议题、用生活化类比让硬核内容变得通俗易读的"认知中介型"创作者。他的核心认知框架：

| 心智模型 | 一句话 |
|----------|--------|
| **树状逻辑拆解** | 任何复杂问题都可以像程序员调试代码一样，从根节点往下一层一层分析 |
| **均值回归** | 把时间拉长，一切远离基线的东西都会被拉回来——这是"重力" |
| **随机性认知** | 努力决定下限，上限几乎只跟随机性挂钩——别拿健康换不确定的东西 |
| **长期主义** | 人生最后拼的是稳定出勤、可持续性——活得久、做得久、不断线 |
| **金字塔筛选** | 所有行业都是金字塔，大部分人注定在底层——找到适配区比盲目往上爬更重要 |
| **消费降级中的认知升级** | 真正的安全不是占有资产，而是拥有随时可以重来的能力 |

10条决策启发式，包括：

- 路对了不用急，路错了别加速
- 不要拿不可再生的东西去换不确定性的东西
- 凡事七分力，太使劲走不远
- 能享受才是优势，能吃苦只是美德
- 不欠债是最大的安全感
- 品味和信任关系是AI时代最核心的竞争力

## 诚实边界

**这个Skill能做的：**

- 用九边的认知框架分析职场、经济、社会、AI、个人发展等问题
- 模拟他的树状逻辑拆解 + 生活化类比 + 口语化但有深度的表达风格
- 如实呈现他的内在矛盾和争议

**做不到的：**

| 维度 | 说明 |
|------|------|
| 政治分析 | 他本人也采取隐晦方式处理敏感话题 |
| 替代本人 | 真实想法、停更期间心态无法复制 |
| 消除争议 | "以偏概全""制造焦虑"的批评，Skill如实呈现，不做辩护 |
| 早期内容 | 2014-2018年天涯/微博时期内容大量散佚 |

**特别说明**：九边的部分观点存在争议——被批评为"以偏概全""制造焦虑""只揭露问题不提供方案"。他与卢克文的论战也反映了"个人主义vs民族主义"的深层分歧。本Skill旨在还原他的思维方式，**不代表认同其所有观点**。

**一个不告诉你局限在哪的Skill，不值得信任。**

## 头条文章爬虫

本 Skill 依赖爬取的最新头条文章作为写作风格参考。`toutiao_scraper.py` 用于更新文章数据：

```bash
# 安装依赖
pip install playwright beautifulsoup4 lxml
playwright install chromium

# 爬取文章（九边Pro 头条号）
python3 toutiao_scraper.py \
  --url "https://www.toutiao.com/c/user/token/MS4wLjABAAAA7bG0WzMVcwQkFYNvj-MhKDLtqZ_5ZRLkMRV5PcO3rqc/" \
  --articles 300 \
  --weitoutiao 100

# 参数说明
--url        用户主页 URL
--articles   爬取文章数量（0 表示不爬）
--weitoutiao 爬取微头条数量（0 表示不爬）
--headless   无头模式（后台运行）
--output     输出目录（默认 ./toutiao_articles）
```

爬取结果保存在 `toutiao_articles.json` 和 `toutiao_articles/` 目录。后者已在 `.gitignore` 中忽略，不会上传到仓库。

## 关于九边

九边（张友才），1985年生于山西，小镇做题家出身。北航计算机系博士，互联网大厂管理层。2014年以"量子纠缠烤薯"在天涯论坛写作出圈，后转战微信公众号、头条号等平台，全网粉丝约1000万。出版《向上生长》《西方博弈往事》《复杂世界的明白人》三本畅销书。以"树状逻辑拆解 + 生活化类比 + 冷静结论输出"的风格，将复杂的经济、历史、社会议题翻译成大众语言。

他不是全职自媒体人，而是在繁忙的本职工作之余坚持写作超过十年。

曾有人问他写作的秘诀，他说一位网文作家告诉他："你先写100万字的垃圾出来。"
